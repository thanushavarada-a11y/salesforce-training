Day 1 Notes
What problem does Salesforce solve?
Salesforce solves the problem of scattered customer and business data. It helps organizations store, manage, and track customer information in one centralized platform. Salesforce also improves communication between teams, automates workflows, and increases productivity.

What is CRM?
CRM stands for Customer Relationship Management. It is a system used by companies to manage interactions with customers, store customer data, track sales activities, provide support, and improve business relationships.

What is an Object in Salesforce? Give one example.
An Object in Salesforce is similar to a database table that stores specific types of data. Objects contain records and fields. Example: A Student object can store student details such as name, roll number, branch, and phone number.

Difference between Salesforce Admin and Developer.
A Salesforce Admin mainly works with configuration and management of the Salesforce platform using no-code or low-code tools. Admins manage users, security settings, reports, dashboards, and workflows.

A Salesforce Developer focuses on building custom applications and advanced functionalities using programming languages such as Apex and Lightning Components. Developers create custom logic, integrations, and automation solutions based on business requirements.

Suggest one real-world application that can be built using Salesforce.
A College Management System can be built using Salesforce. It can manage student records, faculty information, attendance, courses, fee details, and examination data in a centralized system.
