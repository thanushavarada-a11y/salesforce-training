# Task 1: Connect Day 1 + Day 2

CRM concepts like Account, Contact, and Opportunity are stored in Salesforce using Objects. These objects are organized inside Apps to help businesses manage their workflows efficiently. For example, an Account object stores company details, a Contact object stores customer information, and an Opportunity object stores sales deals. All these objects work together inside a Salesforce App to help companies manage customer relationships and sales processes.

# Task 2: Platform Understanding

## What is an App in Salesforce?

An App in Salesforce is a collection of related objects, tabs, and tools designed for a specific business purpose. It helps users access everything they need in one place.

### Example:
A College Management App can include:
- Student
- Faculty
- Course
- Attendance objects

## What is an Object?

An Object is like a database table used to store specific types of business data. Objects contain fields and records.

### Example:
A Student object stores student details such as:
- name
- roll number
- branch
- phone number

## What is a Tab?

A Tab is a user interface element that helps users open and access objects and records in Salesforce.

### Example:
The Student tab allows users to manage student records.

# Task 3: Configuration vs Coding

## When Should We Use Configuration (No Code)?

Configuration should be used when business requirements can be solved using built-in Salesforce tools without programming.

### Examples:
- Creating Validation Rules to prevent invalid data entry.
- Creating Formula Fields to automatically calculate attendance percentage.

## When Should We Use Coding (Apex)?

Coding should be used when advanced customization or complex business logic is required.

### Examples:
- Integrating Salesforce with external applications using APIs.
- Creating advanced automation using Apex Triggers.
